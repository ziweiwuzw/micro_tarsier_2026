# Host gene family analysis

`prepare_cafe5_inputs.py` prepares the TOGA2 gene family matrix and the 13-species time tree. `run_cafe5.slurm` runs CAFE5 with a Gamma model and three rate categories. `extract_focal_changes.py` extracts significant changes on the focal branch.

Set the input matrix, dated tree and CAFE5 paths in the scripts before running them. The input data and enrichment analysis scripts are not included here.
